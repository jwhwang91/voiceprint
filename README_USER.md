# Voiceprint 사용 설명서 (macOS)

> 코딩 몰라도 괜찮아요. 마우스로 클릭만 하면 됩니다.

---

## 1. 이 앱은 무엇인가요?

Voiceprint는 **여러분의 말투(목소리)로 네이버 블로그 글을 대신 써 주는 맥(Mac) 데스크톱 앱**입니다. 여러분이 이미 쓰고 있는 **Claude Code 구독**을 그대로 사용하기 때문에 별도의 API 키를 발급받거나, 결제를 따로 하거나, 코드를 한 줄도 작성할 필요가 없습니다. 사진과 영상을 끌어다 놓고 버튼 몇 개만 누르면, 앱이 사진을 하나하나 살펴보고 여러분의 평소 글 스타일을 흉내 내어 약 2000자 분량의 글을 쓰고, 사진까지 알맞은 위치에 배치해 네이버에 **임시저장**까지 해 줍니다. 모든 작업과 데이터는 여러분의 맥 안에서만 일어나며, 네이버 화면은 직접 눈으로 볼 수 있습니다.

---

## 2. 처음 한 번만 하는 준비

### (1) Claude Code 설치하고 로그인

1. 웹브라우저에서 **claude.ai/code** 에 접속해 안내에 따라 **Claude Code**(claude 명령어)를 설치합니다.
2. 설치가 끝나면 **본인 구독 계정으로 로그인**합니다. (API 키가 아니라, 평소 쓰시는 구독 로그인입니다. 추가 과금 없음!)

> 이 한 가지만 미리 해 두시면 됩니다. Voiceprint는 이 Claude Code를 빌려 쓰는 구조예요.

### (2) 받은 파일 압축 풀기

전달받은 **`VoiceprintStudio-mac.zip`** 파일을 **더블클릭**해서 압축을 풉니다.
- 그러면 **`VoiceprintStudio`** 라는 폴더가 생깁니다. 이 폴더를 **`응용 프로그램`** 이나 **`문서`** 등
  원하는 곳에 옮겨 두세요(폴더째 옮겨야 합니다).

### (3) 앱 실행하기

**`VoiceprintStudio`** 폴더 안의 **`START_MAC.command`** 파일을 **더블클릭**하세요.

- **맨 처음 실행할 때**는 필요한 것들을 자동으로 설치합니다(잠깐 시간이 걸릴 수 있어요). 그대로 기다려 주세요.
- 두 번째부터는 바로 앱 창이 뜹니다.

> 더블클릭했을 때 "확인되지 않은 개발자" 같은 안내가 뜨면, 파일을 **마우스 오른쪽 클릭 → 열기**를 한 번만 해 주시면 다음부터는 그냥 더블클릭으로 열립니다.

---

## 3. 작업 폴더(워크스페이스) 고르기

**작업 폴더(워크스페이스)**는 여러분의 모든 자료(사진, 메모, 완성된 글, 로그인 정보 등)가 보관되는 **하나의 큰 보관함**입니다.

- 기본 위치는 **`~/Documents/VoiceprintWorkspace`** 입니다. (별다른 설정을 안 하면 여기에 저장돼요.)
- 여기에 들어간 자료는 **앱을 업데이트해도 그대로 남습니다.** 안심하세요.
- 폴더를 바꾸고 싶으면, 앱 오른쪽의 **`📂 작업 폴더 바꾸기`** 버튼을 눌러 원하는 위치를 고르면 됩니다.
- **`폴더 열기`** 버튼을 누르면 그 보관함이 파인더(Finder)에서 바로 열립니다.

---

## 4. 새 글 만들기

1. 오른쪽 **새 글 작성** 영역에 **작업 이름(job 이름)** 을 입력합니다. (예: `jeju-cafe`, `2026-spring-picnic` 처럼 영문/숫자 추천)
2. **`+ 폴더 만들기`** 버튼을 누르면 그 이름으로 새 폴더가 만들어집니다.
3. 만들어진 **드롭존(끌어다 놓는 칸)** 에 **사진과 영상을 마우스로 끌어다 놓습니다.** (여러 장 한꺼번에 가능)
4. (선택) **`📝 메모`** 버튼을 눌러, 글에 꼭 넣고 싶은 내용을 적습니다. 가게 이름, 가격, 느낀 점 등을 적으면 글이 더 정확해져요.

> 메모는 **선택 사항**입니다. 메모를 안 써도, 앱이 사진만 보고 글을 써 줍니다. (단, 사진에 없는 가격이나 정확한 상호 같은 건 지어내지 않아요.)

---

## 5. Claude로 글 생성하기

준비가 끝났으면 **`✍️ 이 글 쓰고 발행`** 버튼을 누르세요. 그러면 Claude가 차례대로 이런 일을 합니다.

1. **사진 분석 & 태깅** — 사진을 한 장씩 직접 열어보고 무엇이 찍혔는지 파악합니다.
2. **글쓰기** — 여러분의 평소 말투(페르소나)를 흉내 내어 **약 2000자**짜리 본문을 씁니다.
3. **사진 배치** — 각 사진을 내용에 가장 잘 어울리는 위치에 넣습니다.
4. (선택) **SEO 브리프** — 미리 **`🔑 SEO 브리프 생성`** 을 해 두면, 검색에 잘 걸리는 키워드/제목/태그를 글에 자연스럽게 반영합니다.

> 영상을 넣었다면, **`🎬 영상→움짤(GIF)`** 버튼으로 짧은 움짤(GIF)을 먼저 만들어 두면 글 안에 자연스럽게 들어갑니다.
>
> 글이 다 나오면 **`👀 초안 미리보기`** 로 결과를 먼저 확인할 수 있어요.

---

## 6. 네이버에 저장/발행하기

글이 완성되면 앱이 네이버에 글을 올려 주는데, **여기서 꼭 알아두실 점이 있습니다.**

> ⭐ **앱은 "임시저장"까지만 합니다. 마지막 "발행" 버튼은 여러분이 네이버에서 직접 눌러야 합니다.**

이건 실수나 오류가 아니라 **일부러 그렇게 설계한 것**입니다. 글이 자동으로 세상에 공개돼 버리는 걸 막기 위해서예요. 그래서:

1. 앱이 글과 사진을 네이버 글쓰기 화면에 채우고 **임시저장(임시저장 글)** 해 둡니다.
2. **`🌐 네이버 보기`** 로 네이버 화면을 열어 글을 한 번 훑어봅니다.
3. 내용이 마음에 들면 네이버에서 **직접 `발행` 버튼을 눌러** 글을 공개합니다.

> "글 올리기 끝났다"고 앱이 말해도, **네이버에서 발행을 직접 누르기 전까지는 아직 공개된 게 아닙니다.** 꼭 마지막 발행을 직접 해 주세요.

---

## 7. 로그인 / 보안문자(CAPTCHA) 화면이 뜨면?

작업 중에 네이버 **로그인 화면**이나 **보안문자(CAPTCHA, 자동입력 방지) 화면**이 나타날 수 있습니다.

- 이때는 **눈에 보이는 네이버 화면에서 여러분이 직접** 로그인하거나 보안문자를 입력해 주세요.
- 처음 한 번만 로그인하면 되며, 앱 오른쪽의 **`네이버 로그인(1회)`** 버튼을 이용하면 됩니다.
- **앱은 절대로 로그인이나 보안문자를 몰래 우회하지 않습니다.** 보안은 여러분 손으로 통과하는 것이 안전하고 정상입니다.

로그인/보안문자를 통과하고 나면, 다시 버튼을 눌러 작업을 이어가면 됩니다.

---

## 8. "자가치유(Self-healing)"가 뭔가요?

네이버는 가끔 화면 디자인이나 버튼 위치를 슬쩍 바꿉니다. 그러면 앱이 "발행" 버튼을 못 찾아 실패할 수 있어요. 이럴 때 **자가치유** 기능이 작동합니다. Claude가 **지금 떠 있는 네이버 화면을 직접 들여다보고**, 바뀐 버튼의 위치를 찾아내 **여러분의 작업 폴더에 살짝 고쳐 둡니다.** 이렇게 **최대 3번까지** 스스로 고쳐 다시 시도하고, 그래도 안 되면 멈춰서 여러분에게 알려 줍니다. (오른쪽의 **`🩹 발행 실패 시 자가치유`** 버튼과 관련된 기능이에요. 앱의 원본 프로그램은 건드리지 않고, 여러분 폴더에만 바뀐 내용을 기록합니다.)

---

## 9. 내 파일은 어디에 저장되나요?

모든 자료는 여러분이 고른 **작업 폴더(워크스페이스)** 안에 정리됩니다. 기본 위치는 `~/Documents/VoiceprintWorkspace` 예요. 대략 이렇게 생겼습니다.

```
VoiceprintWorkspace/
├─ input/<작업이름>/
│   ├─ photos/            ← 끌어다 놓은 사진·영상
│   └─ description.txt     ← 메모 (선택)
├─ drafts/<작업이름>/      ← 완성된 글과 배치
│   ├─ post.md             ← 본문 글
│   ├─ layout.json         ← 사진 배치도
│   ├─ SEO_BRIEF.md        ← SEO 전략 (선택)
│   └─ photo_tags.json     ← 사진 분석 결과
├─ personas/               ← 분석된 내 말투 자료
├─ collected/              ← 수집한 과거 글
├─ auth/                   ← 네이버 로그인 정보
├─ config/                 ← 내 설정 파일
└─ logs/                   ← 기록(로그), 화면 캡처
```

> 폴더가 어디 있는지 헷갈리면 앱의 **`폴더 열기`** 버튼을 누르세요. 바로 파인더에서 열립니다.

## 10. 문제가 생겼을 때 (간단 해결 모음)

- **"claude 미설치 / 로그인 안 됨" 같은 안내가 떠요**
  → 2번 준비 단계로 돌아가, **claude.ai/code** 에서 Claude Code를 설치하고 구독 계정으로 **로그인**했는지 확인하세요. 오른쪽 **`▶ Claude 시작`** 버튼으로 다시 연결할 수 있고, **`/status(과금 확인)`** 으로 로그인 상태를 점검할 수 있어요.

- **뭔가 안 돌아가는데 원인을 모르겠어요**
  → 오른쪽 **`🩺 환경 점검`** 버튼을 누르세요. 무엇이 설치돼 있고 무엇이 빠졌는지 알아서 진단해 줍니다. (아무것도 설치하지 않고 점검만 합니다.)

- **영상을 넣었는데 움짤이 안 만들어져요**
  → 영상을 GIF로 바꾸려면 **ffmpeg** 라는 도구가 필요합니다. **`🩺 환경 점검`** 에서 ffmpeg 설치 여부를 확인할 수 있어요. (없으면 안내가 나옵니다.)

- **자세한 기록(로그)을 보고 싶어요**
  → 오른쪽 **`로그 열기`** 버튼을 누르면 기록 폴더가 열립니다. 작업 폴더의 `logs/` 안에 `blog_automation.log`(작업 기록)와 `screenshots/`(화면 캡처)가 들어 있어요.

- **버튼 말고 직접 입력하고 싶어요 (고급)**
  → 앱 아래쪽에는 항상 보이는 검은 터미널 창이 있습니다. 익숙한 분은 여기에 명령을 직접 입력할 수도 있지만, 보통은 오른쪽 버튼만으로 충분합니다.
