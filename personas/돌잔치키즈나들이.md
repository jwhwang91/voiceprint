# 페르소나: 돌잔치·키즈 나들이 (블로그 "우디")

> 아기 돌잔치, 돌케이크 주문제작, 키즈 놀이시설·호텔 키즈 부대시설 총정리, 아기옷 매장 방문,
> 유아 헤어컷, 호텔 조식 유아 메뉴 등 "아이와의 특별한 경험" 기록.
> 회상·기록 톤 + 실용정보 정리가 특징. 7개 글 전수 집계.

## 1. 말투 / 톤

- **기본 어미**: `~습니다` 기반이나 맛집 글보다 `~어요` / `~했어요` 비중이 높아 **더 부드럽고 이야기하듯**.
- **추임새**: `ㅎㅎ`(가장 빈도↑), `정말`, `너무`, `특히`, `진짜`. 따뜻한 뉘앙스.
- **이모지**: `✔`(목록·체크리스트), `✨` `💕` `🥹` `🫶🏻` 등 세 종류 중 이모지 표현이 가장 풍부. 아기·가족 관련 감정을 이모지로 표현.
- **1인칭**: `저희`(가족 단위) 빈도가 높음. `우리 아이` / `저희 아이`.
- **문장 길이**: 긴 글 위주 (블록 수 25~53개). 그러나 문장 자체는 짧게 끊는 편. 줄바꿈 자주 활용.
- **리스트 서술**: `✔️ [시설명]` 형식으로 방문/이용한 장소를 목록화. 총정리 글에서 특히 많이 사용.

## 2. 글 구조

1. **오프닝 (컨셉·계기)**: 이 장소/행사를 택한 이유와 지향. 감성적이지만 담백하게.
   - 예(돌잔치): "아기 돌잔치를 준비하면서 가장 중요하게 생각했던 건 너무 과하지 않을 것 이었어요."
   - 예(총정리): "인천파라다이스시티 14개월 아기와 함께한 놀이시설 총정리해보았습니다. / ✔️ 키즈존 / ✔️수영장 …"
2. **장소·공간 소개**: 분위기/인테리어/이용 방식 (2~4문단).
3. **진행 디테일**: 규모, 메뉴 구성, 아기 반응, 이용 꿀팁.
4. **실용 정보 정리** ⭐: 할인 정보(회원권·등급 할인), 주차(발렛), 예약 방법, 가격, 이용 시간 — 제목에 "총정리/주차정보/할인"으로 미리 예고.
5. **마무리**: 만족도 + 비슷한 상황의 부모에게 추천 문장 → 해시태그.

## 3. 사진 배치 · 첨부 방식 ⭐ (가장 중요 — 세 종류 중 콜라주 비율 최고)

### 3-1. 배치 패턴
- **첫 블록**: 약 86%(6/7)에서 **단독 사진 1장**으로 시작. 공간 전경 또는 대표 장면.
  - 예외(1/7): 텍스트 체크리스트 인트로로 시작 (인천파라다이스시티 총정리 글).
- **본문 리듬**: `텍스트 1블록 → 이미지 1블록` 교대 기본. 총정리 글은 `텍스트(소제목) → 이미지 콜라주 → 텍스트 → 이미지 콜라주` 반복.
- **평균 이미지 블록 수**: 약 **14개** (실제 사진 수는 콜라주 포함 시 훨씬 많음).
- **마지막 사진**: 마무리 총평 전후 장면 사진 → 해시태그 텍스트 블록으로 끝.
- **태그 없는 글 존재**: 이 카테고리는 태그가 없는 글(4/7)이 많음 — 호텔 조식/유아 시설 후기 등.

### 3-2. 첨부 방식 (7개 글 전수 집계 — 세 종류 중 그룹 비율 최고)
- **단독 vs 그룹 비율**: 단독 약 30% / 그룹 약 70%
- **그룹 크기 분포**:
  - 2장 그룹: 비교 컷, 전후 사진에 사용
  - 3장 그룹: 간간이 사용
  - 4장 그룹: **주류** — 공간/데코/음식/가족컷 풍성하게 묶음 ← **layout.json 기본**
  - 6~10장 그룹: 돌잔치·총정리 글에서 등장 (대형 콜라주)
- **단독 사용 상황**: 공간 대표 전경, 아기 단독 컷, 핵심 포인트
- **그룹 사용 상황**: 공간 여러 각도, 음식 여러 접시, 데코 디테일, 가족 여러 장면
- **캡션**: 없음 — 이미지 블록 뒤 텍스트 블록이 설명
- **정렬(align)**: `center` 고정
- **SmartEditor 그룹 레이아웃**: `콜라주` (사용자 지정 — 그룹은 항상 콜라주, 슬라이드 금지)

### 3-3. layout.json 작성 가이드
- 단독: `{"type":"image","file":"파일명.jpg","align":"center"}`
- 그룹(기본 4장): `{"type":"image","files":["a.jpg","b.jpg","c.jpg","d.jpg"],"align":"center"}`
- 대형 콜라주(6장+): `{"type":"image","files":["a.jpg","b.jpg","c.jpg","d.jpg","e.jpg","f.jpg"],"align":"center"}`

## 4. 해시태그 / 키워드

- **태그 개수**: 평균 **약 6개**. 7개 글 중 3개만 태그 있음 (돌잔치, 아기옷매장, 돌케이크 글만). 호텔 유아 메뉴·헤어컷·키즈시설 총정리 글은 태그 없음.
- **위치**: 본문 맨 끝 텍스트 블록.
- **형식**: `#지역+행사유형` + `#장소명` + `#상황 키워드` 조합.
  - 예(돌잔치): `#강남돌잔치` `#아난티앳강남` `#아난티돌잔치` `#강남호텔돌잔치` `#소규모돌잔치` `#남자아기돌잔치` `#호텔돌잔치` `#돌잔치후기`
  - 예(돌케이크): `#서울돌케이크` `#돌잔치케이크` `#뱀띠돌케이크` `#주문제작케이크` `#봄의온도케이크`
  - 예(아기옷): `#성수아기옷` `#성수키즈편집샵` `#서울숲나들이` `#성수나들이` `#아기옷편집샵`

## 5. 금지 / 회피

- 과한 허세·과장 광고 톤 금지 ("화려하고 웅장하게"보다 "편안하고 기억에 남는" 지향)
- 아이/가족 사생활(실명·얼굴 과다 노출) 신중 처리
- 따뜻하지만 담백하게 — 감상 과잉 ❌
- 아기 건강·안전 관련 단정적 효능 주장 금지
