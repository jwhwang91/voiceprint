# 페르소나: <글 종류>

> ⭐ 이 문서는 글 작성(prompts/write_post.md)의 기준이 된다. 구체적·재현 가능하게.

## 1. 말투 / 톤
- 어미 습관: (예: "~했어요", "~더라구요" 혼용 / 반말·존댓말)
- 자주 쓰는 감탄·추임새: (예: "와...", "진짜", "ㅎㅎ", "❤️")
- 문장 길이: (짧고 끊어 씀 / 길게 이어 씀)
- 1인칭 표현: (예: "저는", "우리")

## 2. 글 구조
- 도입부 패턴: (예: 인사 → 방문 계기 1~2문장)
- 본문 전개: (예: 입장 → 메뉴 → 맛 평가 → 총평)
- 마무리 패턴: (예: 별점/추천 여부 + 다음 예고)
- 평균 문단 수 / 글 길이:

## 3. 사진 배치 · 첨부 방식 ⭐ (가장 중요)

### 3-1. 배치 패턴
- 첫 사진 위치: (예: 도입부 1문단 뒤 대표 사진 1장)
- 사진 간격: (예: 1~2문단마다 1장)
- 마지막 사진: (예: 외관/영수증/전체샷으로 마무리)
- 사진 총 이미지 블록 경향:

### 3-2. 첨부 방식 (layout.json 직접 반영)
- 단독 vs 그룹 비율: (예: 단독 56% / 그룹 44% — body_blocks 전수 집계)
- 그룹 크기 분포:
  - 2장 그룹: N블록 (전체 그룹 중 XX%)
  - 3장 그룹: N블록 (XX%)
  - 4장 그룹: N블록 (XX%)
  - 5장+ 그룹: N블록 (XX%)  ← 있으면
- 최빈 그룹 크기: (예: 2장 → layout.json files 배열 기본 크기)
- 사진 캡션: (있음/없음. 있으면 톤)
- 정렬(align): center 고정 (HTML 수집 불가 — 네이버 SmartEditor 기본값)
- SmartEditor 그룹 레이아웃: 콜라주 고정 (HTML 수집 불가 — 사용자 지정: 그룹은 항상 콜라주, 슬라이드 금지)

### 3-3. layout.json 작성 가이드
- 단독 사진: `{"type":"image","file":"파일명.jpg","align":"center"}`
- 그룹/콜라주: `{"type":"image","files":["a.jpg","b.jpg"],"align":"center"}`
  - `files` 배열 크기 = 위 최빈 그룹 크기 기준, 페르소나 패턴 반영

### 3-4. 대표 이미지(썸네일) 선정 기준 ⭐
> 네이버는 글의 **맨 위(첫) 이미지**를 자동으로 썸네일(대표)로 쓴다. 그래서 이 카테고리 글들의
> **첫 이미지가 무엇인지** = 사실상 대표 이미지 패턴이다. 과거 글의 `body_blocks` 첫 이미지를
> 관찰해 적는다.
- **대표가 되는 사진 유형**: (예: 외관 전경 / 시그니처 메뉴 단독 컷 / 공간 전경 / 제품 패키지 대표 컷 / 아기 표정 클로즈업)
- **카테고리(category) 경향**: (첫/대표 이미지의 category 가 주로 무엇인지 — 외관·메뉴음식·내부 등)
- **단독 여부**: 대표는 거의 항상 **단독 사진**이어야 한다(콜라주 X). 첫 블록이 단독으로 시작하는 비율(3-1 참고).
- **write_post 적용**: 글을 가장 잘 대표하는 단독 사진 1장을 **첫 이미지 블록**에 두고 그 블록에
  `"representative": true` 를 단다(딱 한 장, 그룹 금지).
