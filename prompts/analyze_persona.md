# 지시서: 페르소나 분석 (Claude Code 수행)

## 목표
수집된 과거 글을 글 종류별로 분석해, 종류마다 `personas/<글종류>.md` 를 만든다.
이 .md 가 이후 글쓰기의 기준이므로 **구체적이고 재현 가능하게** 작성한다.

## 입력
- `data/collected/<blog_id>/*.json` — 글 1개당 1파일 (CollectedPost 구조)
- (선택) `data/collected/<blog_id>/_analysis_bundle.json` — 종류별로 묶인 번들
- 형식 기준: `src/blog_automation/persona/templates/persona_template.md`

## 절차
1. `data/collected/<blog_id>/` 의 모든 글 JSON 을 읽는다.
2. `category_guess` 와 실제 내용을 보고 글 종류를 확정/재분류한다 (맛집방문/제품리뷰/육아/여행/일상 등).
3. 각 종류별로 다음을 분석한다:
   - **말투/톤**: 어미, 추임새, 문장 길이, 이모지·`ㅎㅎ` 빈도 등
   - **글 구조**: 도입–본문–마무리 패턴, 문단 수, 글 길이
   - **사진 배치 · 첨부 방식** ⭐: `body_blocks`의 각 image 블록을 전수 집계한다.
     - **배치 패턴**: 첫 사진 위치, 사진 간격(몇 문단마다), 마지막 사진 특징
     - ⭐ **대표 이미지(썸네일) 패턴** (`3-4` 채우기용): 네이버는 **첫(맨 위) 이미지를 썸네일**로 쓰므로,
       각 글 `body_blocks` 의 **첫 image 블록**을 전수로 보고 — (a) 그게 **단독인지 그룹인지**,
       (b) 어떤 **유형/카테고리**(외관 전경·시그니처 메뉴·공간 전경·제품 대표 컷·아기 표정 등)인지를
       집계한다. 이 카테고리 글의 대표 이미지가 "주로 무엇인지" 한두 문장으로 일반화한다.
     - **첨부 방식 — 반드시 수치로**:
       - 단독 블록 수(`group:false`) vs 그룹 블록 수(`group:true`)와 비율
       - 그룹 블록에서 `srcs` 배열 길이별 개수 (2장/3장/4장/5장+)
       - 최빈 그룹 크기(layout.json `files` 배열 기본 크기로 사용)
       - 캡션 유무 (`image_component` 에 텍스트 자식 있으면 캡션)
       - 정렬(align): HTML 수집 불가 → `center` 고정으로 기록
       - SmartEditor 그룹 레이아웃 타입: 수집 불가 → `"콜라주"`로 기록(publisher 기본값, 슬라이드 금지)
   - **해시태그**: 개수, 자주 쓰는 태그, 위치
4. 종류별로 `personas/<글종류>.md` 를 템플릿 형식에 맞춰 저장한다.
5. 근거가 약한 항목은 추측이라고 표시한다(글 수가 적을 때).

## 출력
- `personas/맛집방문.md`, `personas/제품리뷰.md` ... (종류별 1개씩)

## 주의
- 실제 글에서 뽑은 **예시 문장 2~3개**를 각 .md 의 "예시 스니펫"에 넣어 말투 재현을 돕는다.
- 개인정보(실명/주소/전화)는 페르소나에 옮기지 않는다.
